COMO SALVAR PDF
1. Entre no módulo desejado e informe os dados.
2. Clique em "Gerar PDF do módulo" na barra superior.
3. Será aberta uma página de relatório contendo apenas o módulo ativo.
4. Clique em "Imprimir / Salvar PDF".
5. No Windows/Edge ou Chrome, escolha como destino "Salvar como PDF".
6. No celular, use a opção de imprimir e "Salvar como PDF", caso disponível no sistema.

COMO ATUALIZAR O GITHUB
1. Extraia o conteúdo do ZIP.
2. Atualize os arquivos no repositório INSTRUMENTACAO-PRO, incluindo a pasta assets.
3. Verifique o GitHub Pages após o commit.
4. Abra o aplicativo com internet para instalar o novo cache offline.
5. Teste novamente sem conexão.

OBSERVAÇÃO TÉCNICA
O critério 5D a montante do medidor e 2D a jusante é retirado da figura do manual fornecido. A indicação "máx. 2 DN" no original deve ser conferida com o manual do sensor e a instalação real. O aplicativo mantém o critério 2D solicitado pelo usuário como referência ilustrativa; não substitui o manual do equipamento ou o projeto de instalação.
