Instrumentação PRO - versão 1.5.0

Atualizações desta versão:
- Módulo 02: remoção da calculadora de Placa de orifício.
- Módulo 02: inclusão do ilustrativo de instalação mínima do medidor de vazão.
- Novo campo para diâmetro do tubo do medidor, com cálculo automático de 5D antes e 2D depois do medidor.

Para atualizar no GitHub Pages:
1) Extraia o ZIP.
2) Substitua os arquivos do repositório.
3) Aguarde a publicação do GitHub Pages.
4) Atualize o aplicativo instalado para recarregar o novo cache.
